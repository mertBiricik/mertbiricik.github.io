Selected work

Things I built for research projects and for myself. Each entry says what the problem was, what I did and what came out of it.

  1. 01 09/2024 – Present

    EnerjiVeri: 100 Years of Turkish Energy Data

    TÜBİTAK 1001 project No. 323K520, sole web developer

    Problem. A hundred years of Turkish energy production, consumption and policy data was spread across CSV files and PDFs.

    What I did. I built the project's Turkish-language portal that brings it together, with time-series charts, sector breakdowns and interactive dashboards.

    Result. The portal is live and used by the project's researchers and policy stakeholders ("Energy Strategies in the Second Century of the Republic").

    Built with

    • Python
    • Data Visualization
    • Time-Series
    • Web Portal
    • ETL

  2. 02 2024 – 2025

    Tune2Travel: Music Videos and Destination Marketing

    TÜBİTAK 1001 project, data infrastructure and NLP

    Problem. The project studies how music videos shape the way people see a travel destination, which needs a lot of multilingual social media data.

    What I did. I built the data side: collecting videos and comments through the YouTube API, the ETL pipelines, and the NLP and ML models that pull cultural and sociological signals out of the comments.

    Result. Marketing and sociology researchers on the project use it to compare patterns across thousands of music videos in several languages.

    Built with

    • Python
    • NLP
    • spaCy
    • Gensim
    • YouTube API
    • ETL
    • Selenium
    Visit site
  3. 03 2024 – 2025

    OSINT-Driven SCADA Threat Discovery

    Field assessment on a SCADA testbed in Milan

    Problem. Power distribution operators have no structured way to combine open-source intelligence about their assets with AI-based protection.

    What I did. I did a hands-on OSINT vulnerability assessment of a SCADA testbed in Milan and worked on a framework that pairs OSINT-based threat discovery with AI-based protective controls.

    Result. Published at IEEE UPEC 2025.

    Built with

    • OSINT
    • SCADA
    • Threat Discovery
    • Network Security

  4. 04 2025

    Basketball RAG Agent

    Retrieval-augmented generation for Turkish basketball rules and league data

    Problem. Generic search tools fail at semantic, domain-specific basketball questions and break entirely on Turkish league data.

    What I did. I built a RAG system with two sides: a vector store of 873 official rule documents and a FastAPI server over 17,000+ Turkish league games, routed by an intent classifier and exposed through a Gradio UI.

    Result. Answers bilingual questions about both the rules and league statistics from a single conversational interface.

    Built with

    • LangChain
    • Ollama
    • RAG
    • FastAPI
    • Gradio
    • Python
    Source code
  5. 05 2023 – 2024

    C/C++ Systems Benchmarking Suite

    Custom allocator, scheduler, shell and HTTP server

    Problem. Coursework rarely connects OS theory (allocation, scheduling, IO) to measurable performance on a single machine.

    What I did. A Makefile-driven suite with a custom memory allocator, a process scheduler, a UNIX shell and a minimal web server, each with reproducible benchmarks.

    Result. A reusable setup for systems performance experiments and a teaching reference.

    • C

    • Makefile
    • Linux
    • System Programming
